## 时间轴上方那一排

从左到右：播放与时间码、**节拍 BPM**、**offset**、**拍/小节**、**吸附**、**长度**、缩放、**预览质量**、曲线。

`offset` 是「第 0 拍落在第几秒」。多数工程填 0 就行；音乐有前奏时填前奏长度，网格就会对齐到实际的第一拍上。这个值是独立参数，不是从 0 秒推出来的。

**吸附**有五个档：小节、拍、半拍、帧、自由。它同时决定网格线的间距和拖拽的吸附步长 —— 两者是同一个值，不会出现「网格画在小节上、吸附却吸到半拍」。

## 三条轨的类型

| 轨 | 放什么 |
| --- | --- |
| 视觉轨（V1、V2…） | 算法片段、素材片段、文本片段 |
| 特效轨 | 特效片段。它是**调整层**，影响它下面的轨道 |
| 音频轨（A1…） | 音乐或参考音 |

**V1 在最上面，是最前景。** 新加的轨道会落在列表末尾，也就是最底层 —— 这一条和多数剪辑软件相反，但它和「图层」的直觉一致：上面的遮住下面的。

特效片段必须排在源片段**之前**（列表更靠上）才会影响它。放在下面就成了孤立的一层，什么也改不了，而且不会有任何报错。

点轨道名左边的圆点是启用 / 禁用这条轨。

## 片段的手势

| 想做的事 | 怎么做 |
| --- | --- |
| 移动 | 拖动 |
| 改长度 | 拖左右边缘 |
| 框选多个 | 在空白处拖动 |
| 加选 / 减选 | `Shift` + 单击 |
| 整组移动 | 拖动已选中的任一片段（带音频时只能水平移动） |
| 重命名 | `F2` |
| 复制 / 剪切 / 粘贴 | `Ctrl+C` / `Ctrl+X` / `Ctrl+V`（粘贴落在播放头） |
| 在播放头处切分 | `S` |
| 删除 | `Delete` |
| 上移 / 下移一轨 | `Alt+↑` / `Alt+↓` |
| 在鼠标位置新建 | 右键 |

## 曲线

选中一个片段按 `K` 打开曲线编辑器。它能给**任何 range 参数**打关键帧，也能直接画贝塞尔手柄。不给枚举和算法 id 打关键帧，这是设计选择 —— 那种「关键帧」没有中间态可言。

曲线键绑的是 `片段实例 + 参数名`。换掉片段的生成器时，不属于新生成器的曲线会被一并删掉，不会留下读不到的死键。

## 预览质量

预览质量只影响渲染分辨率，**不影响导出**。它决定了你在这一秒里看到的清晰度，也直接决定帧率读数。

时间轴右下角的 fps 是**渲染帧率**，不是画面更新率。排查卡顿时先看这个数，再看是不是视频解码在拖后腿。
