## 桌面便携包

下载后解压到一个你找得到的位置，运行目录里的可执行文件即可。它不写注册表、不装服务，解压出来的目录整个删掉就算卸载干净。

工程**不会**存在应用目录里，也不需要管理员权限。

## 浏览器

主应用本身是 Web 应用，在浏览器里也能跑，但有一个硬前提：**必须是 secure context** —— `https` 或者 `localhost`。这不是我们的限制，是浏览器的：选择工程目录用的 `showDirectoryPicker` 只在这个条件下存在。

如果条件不满足，你会看到一个能力闸门页面，上面写着缺哪一项，而不是一个白屏。

## 第一次打开

空状态会给两个入口：**新建工程**和**打开演示工程**。演示工程是一段 24 秒、120 BPM 的完整工程，包含六条视觉轨、一条程序生成的音乐轨，还有一个标题排版片段。想先看看这东西能干什么，点它就行。

## 保存

| 动作 | 快捷键 | 说明 |
| --- | --- | --- |
| 保存 | `Ctrl+S` | 第一次保存会问你要一个目录 |
| 另存为 | `Ctrl+Shift+S` | 选一个新目录，原工程不动 |

工程在磁盘上是一个目录：里面是工程文件，加上你用到的素材。把它整个复制走就是备份，放进 git 也只是一个普通目录。

## 左侧竖栏

从上到下：关于、快捷键、保存工程、媒体池、工程、插件、导出、设置、打开试炼场，最下面是亮暗切换。

- **媒体池**：这个工程用到的全部素材，包括还没放到时间轴上的
- **工程**：工程名、位置、最近的工程
- **插件**：装了哪些、缺了哪些
- **试炼场**：一个单独的页面，用来单个试特效和生成器，不影响当前工程

## 关了程序会不会丢

会提示。脏工程直接关窗口时，应用会拦一次，让你决定保存还是丢弃。

另外它还会定期写一份草稿，下次启动时如果发现草稿比磁盘上的工程新，会问你要不要恢复。
