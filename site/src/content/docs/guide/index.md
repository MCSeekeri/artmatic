Artmatic 的工作流只有三个动作：**让算法算出画面**、**把它剪到拍上**、**导出来**。三件事分别在工程视图、时间轴和导出面板里，彼此没有隐藏状态。

## 从哪开始

| 你手上有什么 | 从这篇开始 |
| --- | --- |
| 刚下载，还没打开过 | [安装与启动](/guide/install/) |
| 已经能打开，但时间轴看不懂 | [时间轴与节拍](/guide/timeline/) |
| 想做出「不像滤镜」的故障画面 | [特效](/guide/glitch/) |
| 想做标题、字幕、动效字 | [排版编辑器](/guide/typography/) |
| 想交付成片 | [导出](/guide/export/) |

## 三个视图是什么关系

工程视图是主界面：左边竖栏切面板，中间预览，右边检查器，下面时间轴。排版编辑器是**同一个工程的第二个视图** —— 它不是新文件，也不是弹窗，双击一个文本片段就进去，回来还是同一个工程。

## 关于快捷键

应用里有一份完整的快捷键表：左侧竖栏的**键盘图标**（提示文字「快捷键」）。这份文档只在容易记错的地方复述，比如「K 打开曲线」「S 在播放头处切分」，权威版本永远在那个面板里。
