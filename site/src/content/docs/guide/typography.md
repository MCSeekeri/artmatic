## 怎么进去

双击时间轴上的文本片段；或者在工程视图里双击文本类素材。排版编辑器是**同一个工程的第二个视图**，不是新文件、也不是弹窗 —— 退出来还是原来那个工程，撤销栈也是同一份。

## 界面分四块

| 区域 | 干什么 |
| --- | --- |
| 顶部 Ribbon | 五个标签页：开始、设计、插入、动效、视图 |
| 中间画布 | 拖、缩放、框选；参考线自动吸附，按住 `Alt` 临时关掉吸附 |
| 右侧面板 | 图层 / 元素属性 / 脚本 |
| 底部 | 关键帧面板：选中元素再加属性就能打点 |

Ribbon 里的分组按你熟悉的顺序排：复制格式、字体、段落、水平对齐、垂直对齐、对齐、分布、层级。

## 元素

文字、形状、图片都是元素，同一个手势系统：

| 想做的事 | 怎么做 |
| --- | --- |
| 选中 / 加选 | 单击 / `Shift`+单击 |
| 框选 | 空白处拖动 |
| 移动 | 拖动（自动吸附参考线，`Alt` 临时关） |
| 移动 1px | 方向键（`Shift` ×10） |
| 全选 | `Ctrl+A` |
| 取消选择 | `Esc` |

文字可以是点文字，也可以是有框的段落文字。形状支持布尔运算，字形能转成路径之后参与运算 —— 所以「把字的某一部分切掉」在这里是常规操作。

## 动效

动效预设挂在元素上，按节拍走。逐字入场、逐元素位移、颜色循环这些都是预设；要更细的控制就去底部关键帧面板手动打点，或者给某个参数画曲线。

## 它和主时间轴的关系

排版文档里的时间是**相对片段起点**的，片段在时间轴上的位置决定它什么时候出现在画面里。所以调整时间轴上的位置，等于整体挪动这段排版动画的入场时刻 —— 不需要重新排一遍。

## 发布出去的排版

排版文档是工程的一部分，跟着工程走。要用到别的工程里，复制元素或者复制整个文档都行：右侧面板的脚本页签可以拿到当前文档的结构。
