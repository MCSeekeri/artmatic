# Artmatic

面向算法艺术与故障艺术的 Web 原生时间轴工具 —— 把算法艺术和故障艺术**按音乐结构编排**起来：
统一时间轴、按拍吸附、可打关键帧、确定性逐帧导出。

纯前端，无后端、无账号、不需要联网。工程是**磁盘上的一个目录**，整个目录可以直接拷走。

> 想改代码请看 [AGENTS.md](AGENTS.md) —— 架构、硬约束、数据模型与测试约定都在那里，
> 改架构 / 构建方式 / 测试约定之前先更新它。

---

## 前置依赖

| 项 | 要求 |
|---|---|
| 运行时 | Node.js 20.19+ / 22.12+（跑构建与脚本） |
| 包管理器 | [bun](https://bun.sh) —— **只有它**。lockfile 只有 `bun.lock` 一份，见下方说明 |
| 浏览器 | **Chrome / Edge 最新版**。依赖 File System Access（工程读写）、WebCodecs（MP4 编码）、WebGL2（合成） |
| 运行环境 | 必须处于 **secure context**（`localhost` 或 HTTPS）。`file://` 打开不行 —— 上述 API 在非安全上下文里不存在 |
| 部署 | 无后端，`build` 产物是纯静态文件，可放任意静态托管 |

**发行版是桌面应用**（`desktop/` 的 Electron 宿主，免安装便携目录），不需要装浏览器。
浏览器版只作开发与试玩：Firefox / Safari 缺 File System Access 与 WebCodecs 的 H.264，不可用。

## 功能

| 模块 | 内容 |
|---|---|
| 时间轴 | 多轨（音频单独成轨）、Canvas2D 网格与波形、拖拽 / 拍吸附 / 切分 / 跨轨拖拽、三种可配置的重叠策略、事务式撤销栈；**段落标记** + 「节奏 / 标准」两种标尺形态 |
| 关键帧 | 每个参数一条曲线，`linear / step / smooth / bezier`，曲线编辑器可拖贝塞尔手柄、Shift 批量改插值 |
| 算法生成器 | Rule 30 / 90 / 110 元胞自动机（Worker 烘焙）、生命游戏（固定步长 + 快照 + seek 重放）、Mandelbrot 分形（逐帧实时） |
| 故障特效 | slices / channel-split / pixelate / echo 拖尾（ping-pong 反馈）/ scanlines；**片段即调整层**，放在哪一层就只作用于它下面 |
| 转场 | 收录 gl-transitions 集合（逐条核对许可），以剪切点为中心的出画转场 |
| 片段调整 | 变换 / 不透明度 / 混合模式；**亮度键抠图**、**四角透视**、**裁剪**（四边按源比例收窗，算法 / 排版 / 图片 / 视频都适用） |
| 排版 | 独立编辑页（PowerPoint 式 Ribbon）、多元素（文本 / 矢量图形 / **Lucide 图标** / 图片）、CSS 动画、对齐与层级、画布内拖拽缩放旋转 + 智能参考线；**画幅可改**（预设比例 / 锁比例 / 缩放内容）、**上屏大小可缩放，不必铺满全屏**；光栅化成纹理后走普通合成链，**因此可以被特效影响** |
| 音频 | 导入音频（波形可视化）、播放与工程时间同步、**自动估计 BPM 与拍偏移**（也可手改）、导出时离线混流 |
| 素材 | 导入视频（帧精确取帧）与图片：默认**引用**本机原文件，可「收集到工程」；未使用素材可移进回收站 |
| 导出 | **MP4（H.264 + AAC，含音轨）**、**PNG 序列（.zip）**、**GIF（可指定区间 / 宽度 / 帧率）**，展示进度、可取消 |
| 工程 | 目录持久化（`project.json` + 素材台账 + 素材目录）、原子写 + 备份副本、素材哈希校验、目录句柄跨会话保留 |
| 多工程 | 顶栏选项卡就是工程：同一页里开多份、点页签切换。每份有自己的素材仓、播放头、选中态与当前视图 |
| 界面 | 亮 / 暗主题 + 自定义主题色 + 字号缩放；工程选项卡、时间轴轨道、排版图层均可拖曳排序 |

## 快速开始

```bash
# 安装依赖。**只用 bun**：npm / yarn / pnpm 会写出各自的 lockfile 与 bun.lock
# 分叉，而两边版本不一致时不会有任何报错（详见 AGENTS.md §6）。
bun install

# 开发
bun run dev          # http://localhost:5173

# 构建与本地预览
bun run build        # 产物在 dist/
bun run preview      # http://localhost:4173

# 桌面版（发行形态）
bun run desktop:artifact   # build + 打免安装便携目录到 release/Artmatic-<版本>-win32-x64/
bun run desktop:smoke      # 在打包产物里验 preload / IPC / 素材 Range 读
```

### 部署

`bun run build` 产出的 `dist/` 是纯静态站点，直接上传到任意静态托管（Vercel / Netlify /
Nginx / 对象存储均可）。**无需任何服务端配置**，也**不需要 COOP/COEP 之类的特殊响应头**。

唯一的硬性要求是**必须通过 HTTPS 提供**（本机 `localhost` 除外）—— 否则浏览器的
File System Access 与 WebCodecs 会被禁用，表现为「保存按钮点了没反应」「导出 MP4 不可用」。
另外两个 HTML 入口（主应用 `/` 与试炼场 `/lab/`）都要保证能访问到。

### 开发者命令

```bash
bun run check        # 类型检查
bun run test         # 单元测试（纯函数）
bun run test:e2e     # Playwright 端到端（自构建 + 自起 preview + 系统 Chrome）
```

E2E 用本机 Chrome（`channel: 'chrome'`），**不需要** `playwright install`。

## 使用注意事项

**工程与保存**

- 首次保存会让你选一个目录，之后工程就是这个目录（`project.json` + 素材文件）。
  浏览器弹的是系统授权框，**选目录那一下必须有你的点击**，所以「打开最近工程」只能手动点，
  刷新页面不会自动恢复。
- 导入的素材默认是**引用**（本机原文件，工程里不复制），媒体池里有「引用」徽标；
  右键「收集到工程」才把副本写进 `assets/`。换机器或要打包工程之前先收集。
- **自动保存**：在 2 秒静默后写入。有工程目录就写 `project.json`（不轮转 `.bak`）；
  没有目录则写本地草稿，下次启动时横幅会问要不要恢复。
- 媒体池「移除」只解除引用，**字节文件留在 `assets/`**。要真删去「工程」面板的
  「未使用素材」：先移进 `assets/.trash/`，那里还能手动找回；「彻底删除」才是销毁。
- 关闭有未保存改动的工程会弹确认；直接关标签页 / 刷新也会被浏览器拦一次。
  顶栏工程页签上的圆点表示「有未保存改动」。

**时间轴**

- **拖动期间不结算重叠策略**：被拖片段自由跟随鼠标（允许视觉重叠，非法落点有红框预告），
  松手时才按 `拒绝 / 挤开 / 吃掉` 结算一次。例外是「缩放 + 拒绝」——它是单边钳制、
  非破坏性，实时生效。
- **工程时长与素材长度无关**：工具条上的「时长」可以任意改，片段拖出末尾会自动把工程撑长；
  导入音频只是新片段的默认长度，不会被工程时长截断。
- 拖片段可以跨轨（音频片段只能进音频轨）；双击片段 = 打开它自己的编辑器，**不切分**，
  切分用 `S` 键或检查器里的按钮。
- 工具条上的形态按钮在「节奏（小节.拍，吸附默认开）」与「标准（分:秒.帧，吸附默认关）」
  之间切换；段落标记画在标尺上方，双击改名、右键在鼠标处切一刀。
- 音频片段两端的小三角是**淡入 / 淡出**手柄，拖动一笔撤销，导出与预览共用同一条包络。

**导出**

- MP4 走主路径（H.264 + AAC，含音轨），PNG 序列是逃生舱（逐帧交给达芬奇 / Affinity 精修），
  GIF 用于**直接发出去**（256 色、没有音轨，但哪儿都能播）。
- 导出会产生真实的大文件，按钮上**点之前就显示预计体积**。
- MP4 与 PNG 的导出范围是整个工程时长，不是选区。
- **GIF 可以指定区间**，另外还有宽度与帧率两个档位。它的体积与「时长 × 面积」成正比，
  所以这三个旋钮就是它的全部体积控制手段 —— 一段 24 秒的片子整段导成 480px 的 GIF
  是十几 MB，只取几秒才是它能被发出去的形态。

### 快捷键

| 键 | 作用 |
|---|---|
| Space | 播放 / 暂停 |
| S | 在播放头处切分选中片段 |
| Delete / Backspace | 删除选中片段 |
| K | 打开选中片段的关键帧曲线编辑器 |
| Alt + ↑ / ↓ | 选中片段上移 / 下移一轨（跳过装不下的轨道） |
| Esc | 中止正在进行的拖拽 / 关闭弹层 |
| Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl + 滚轮 | 以鼠标为锚缩放时间轴 |
| Ctrl+S / Ctrl+Shift+S | 保存工程 / 另存为（首次保存会问目录） |

标尺拖动 = scrub 播放头；右键轨道 = 在鼠标位置新建片段；轨道行双击名字 = 重命名；
轨道行的 `⋯` = 该轨的二级菜单。设置面板里可以为从 Premiere / After Effects / 达芬奇
迁移过来的用户切换快捷键方案。

### 排版编辑页

顶部是 PowerPoint 式的 Ribbon（**开始** / **插入** / **动画**，以及选中对应元素才出现的
**图形格式** / **图片格式** Contextual Tab），窗口窄时面板横向滚动、高度固定；
中间是所见即所得的画布，右侧是图层列表。

| 操作 | 作用 |
|---|---|
| 单击 / Shift+单击 | 选中元素 / 加选 |
| 双击文本框 | 进入文本编辑；单击文字内部放光标，单击边框退回选中 |
| 空白处拖动 | 框选 |
| 拖动元素 | 移动（自动吸附参考线；按住 Alt 临时关吸附） |
| 方向键 | 移动 1px（Shift ×10） |
| Ctrl+A / Esc | 全选元素 / 取消选择 |
| Space | 播放 / 暂停（驱动 CSS 动画） |

「插入」组里可以放文本框、图片，以及 **Lucide 全量图标**（1800+，带搜索、可一次多选；
插进来的是矢量图形而不是位图，所以描边颜色 / 线宽 / 混合模式都能继续调）。

画布下方可以调缩放；点标题栏的尺寸读数可以改画幅（宽高、锁比例、按工程 / 16:9 /
9:16 / 1:1 / 4:5 预设）与上屏「大小」。「缩放内容」决定改画幅时元素是跟着重排，还是留在
原来的像素位置。

画幅和上屏大小是两件事：画布尺寸是设计分辨率，上屏大小是它在你画面里占多少。画布按
「装进去」显示，所以**同比例改像素，上屏大小不变** —— 弹层里那行「画面上 W × H」就是
实际占位，看着没变不是没生效。

Ribbon 里的「动画 → 转为图片」会把当前排版烘焙成一张 PNG，片段变成普通图片源
（省性能，也方便交给别的工具精修）。

### 参数控件（数字框 drag-to-tweak）

| 操作 | 作用 |
|---|---|
| 单击数字框 | 进入文本编辑（全选，直接打字覆盖） |
| 横向拖动数字框 | 连续改值 |
| Ctrl + 拖动 | 吸附到步长整数倍 |
| Alt + 拖动 | 精细，灵敏度 ×0.1 |
| Shift + 拖动 | 粗调，灵敏度 ×10 |
| 拖动中按 Esc | 取消这次拖动，恢复原值 |
| ↑ / ↓（聚焦数字框） | 按步长增减（Shift ×10） |

拖动到窗口边缘时控件会自动进入 Pointer Lock（光标隐藏、位移不再受屏幕边界限制），
Esc 退出并取消这次拖动。
